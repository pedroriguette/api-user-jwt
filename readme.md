## Api com autenticação e autorização

### Projeto desenvolvido com o intuíto de aprender a implementar autenticação e autorização em uma API RESTful utilizando JWT (JSON Web Tokens), Middleware, Node.js e Express.

## Funcionalidades:

- Apenas Admin pode criar, atualizar e deletar usuários.

## Dependências:

- bcryptjs
- express
- jsonwebtoken
- uuid
- dotenv

## Instalacão de dependências:

```bash
npm install
```
